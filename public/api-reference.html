Connected API

Endpoint: /.netlify/functions/api. Requires a verified Supabase Bearer token and organization membership.

GET returns workspace, attachments and events. POST accepts validated commands with revision checking:

{
  "action": "mutate",
  "expectedRevision": 4,
  "requestId": "a-new-uuid-per-intent",
  "command": { "type": "saveRecord", "entityId": "module-id",
    "record": { "id": "record-id", "code": "S001" } }
}

Commands: configure, stageProposal, publish, discardDraft, restoreVersion, saveRecord, deleteRecord, comment, approval. Unknown operations and identity/tenant overrides are rejected. 409 means refresh and review before retrying.

Private files: attachmentInit → PUT signed URL → attachmentComplete; attachmentUrl authorizes a short-lived download and attachmentDelete removes the object.

Full setup and live verification checklist: docs/BACKEND.md in the repository. External services require configuration. Outbound webhooks are not enabled.
